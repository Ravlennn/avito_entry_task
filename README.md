# Avito Entry Task — классификация автоматизированного трафика

## Задача

Для каждой `cookie_id` предсказать вероятность автоматизированного трафика. Основная метрика — **Precision при Recall ≥ 0.70**, рассчитанная через `metric.py`.

## Результат

- **Baseline CatBoost:** `0.3590` на временной валидации.
- **Итоговая модель:** `0.8593` на временной валидации.
- **Результат проверки `submission.csv`:** `0.88472`.

## Решение

Анализируем события в суточном окне каждой cookie, удаляем полные совпадения строк и строим поведенческие признаки. Итоговая модель — один **CatBoost** с 75 признаками: 65 признаков поведения, 6 агрегатов истории просмотров и избранного за предыдущие три дня и 4 признака пересечения с ранее размеченными посетителями объявлений. 
Промежуточные варианты, включая ансамбль двух CatBoost, сравниваем на временной валидации.

## Запуск

Нужен Python 3.13. Поместите `train.csv`, `test.csv` и `events.csv.gz` в папку `data/` в корне проекта. Из корня проекта установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Откройте `main.ipynb` и выполните все ячейки по порядку. 

Ноутбук создаст `submission.csv` в корне проекта.
